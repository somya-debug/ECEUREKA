# Sample data and test cases

Everything here is plain JSON and is checked by `npm test` (`tests/samples.test.mjs`).

| Path | What it is |
|---|---|
| `problems.json` | Catalog of all 24 problems: id, difficulty, parts provided, optimal part count, number of tests and hints. Generated by `npm run catalog`. |
| `solutions/<problem-id>.json` | A **reference solution** for every problem. It must be *Accepted* using exactly the optimal number of parts (score 100%). |
| `negative/<name>.json` | **Common mistakes** (burned LED, short circuit, floating input, wrong PWM pin, unpowered servo, LED loading a divider, blocking `delay()`, …) with the verdict and message the judge must give. |

> **Spoiler warning:** `solutions/` contains full answers. Learners should try the problems first.

## Sample format

```json
{
  "problem": "night-light",
  "title": "Night Light",
  "difficulty": "Easy",
  "expected": { "verdict": "Accepted", "used": 4, "score": 100 },
  "circuit": {
    "parts": [ { "id": "LDR1", "type": "LDR", "x": 290, "y": 80 }, "…" ],
    "wires": [ ["mcu.5V", "LDR1.1"], ["LDR1.2", "mcu.A0"], "…" ]
  },
  "code": "function setup() { … }\nfunction loop() { … }\n"
}
```

Negative samples replace `expected` with `{ "verdict": "Wrong Answer", "messageIncludes": "burned out" }` and add a `description`.

- **Pin keys** are `<partId>.<pin>`. The Arduino is `mcu` (`mcu.D2`–`mcu.D13`, `mcu.A0`, `mcu.A1`, `mcu.5V`, `mcu.GND`).
- **Part types:** `LED`, `RES`, `BTN`, `BUZ`, `LDR`, `POT`, `RGB`, `SEG`, `PIR`, `SRV`, `SR`. Part ids are the type plus a number (`LED1`), and checks refer to them by id.
- `x`/`y` are board coordinates (760 × 520) and only matter for display.

## Judge a sample from the command line

```bash
npm run judge -- samples/solutions/charlie-six.json
npm run judge -- samples/negative/*.json
```

## Open a sample in the app

The app keeps your work for each problem in `localStorage` under `cc.p.<problem-id>`. To load a sample, open the app, press F12, and run this in the console (here for `night-light`):

```js
const s = await (await fetch('samples/solutions/night-light.json')).json();
localStorage.setItem('cc.p.' + s.problem, JSON.stringify({ parts: s.circuit.parts, wires: s.circuit.wires, code: s.code }));
location.hash = '#/p/' + s.problem; location.reload();
```

`fetch` needs the app to be served over HTTP (`npm start`). If you opened the file directly, paste the JSON instead.
